Name: Yelaman Group:IT-2502
Link: https://asik6web.netlify.app
Task 0. Setup
Added jQuery from CDN, wrote $(document).ready() and printed "jQuery is ready!" in console.

Task 1. Selectors & CSS
Name, headline and intro on top. Used tag, id and class selectors, .text(), .html(), .css(). Two buttons for light and dark theme.

Task 2. Visibility Methods
"About Me" section with status and fun facts. Buttons Hide, Show, Toggle.

Task 3. Fade Methods
Three photos (my car and a wolf), buttons use .fadeIn(), .fadeOut(), .fadeToggle().

Task 4. Slide Methods
Three headings with panels under them. Click on heading = .slideToggle(). Extra buttons use .slideDown() and .slideUp().

Task 5. Add & Remove Elements
List of 4 skills, input and three buttons (.append(), .prepend(), .remove()). Empty skill can't be added, shows error.

Task 6. Modifying Attributes
GitHub link, button changes it to LinkedIn with .attr().

Task 7. Form Interaction
Name and Email inputs, text shows live under the form with .val() and .text().

Task 8. Basic Animation
Three skill bars start with 0 width. "Animate My Skills" button animates them to different widths (90%, 65%, 75%) with .animate(). Click again - back to 0.

Summary
First I made the HTML for all tasks, then wrote the jQuery task by task and tested each one in the browser. The hardest part was Task 8 because I needed a variable to know if bars are open or closed. Then I uploaded everything to GitHub and turned on GitHub Pages.
